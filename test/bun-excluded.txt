# Test files `pnpm run test:bun` (scripts/test-bun.ts) leaves out of the Bun
# run, one per line: the file, a colon and a space, and the Node-only feature
# it needs. `pnpm run test` runs every file under Node.

test/node/node-semantics.test.ts: Node's fs.realpath, which follows a symbolic link before a later `..` (Bun 1.3.14 normalizes `..` first); Node's child_process.spawn, which searches an empty PATH entry as the current directory; and module.syncBuiltinESMExports(), which carries a patched fs.promises.rename into node:fs/promises imports
test/rules.test.ts: Node's list of built-in modules (node:module builtinModules), from which scripts/check-rules.ts tells a Node built-in from a package; Bun 1.3.14's list also names undici, ws, bun and bun:*, so under Bun the checker takes import("undici") for a built-in
test/drivers/claude/sdk-install-node.test.ts: module.syncBuiltinESMExports(), which carries a patched fs.promises.mkdir into the claude driver's node:fs/promises imports, so a tarball can change on disk at the moment it is unpacked
test/node/process-node.test.ts: module.syncBuiltinESMExports(), which carries a patched fs.statSync and child_process.spawn into src/node/process.ts's imports, so a command can appear right after the executable search; and Node's child_process.spawn errors, which the process service's spawn errors must match
test/drivers/claude/credential-copy-back-node.test.ts: module.syncBuiltinESMExports(), which carries a patched fs.renameSync into test/recordings/credential-file.ts's node:fs import, so another Claude Code session can save at the moment between the copy-back's comparison and its replace
